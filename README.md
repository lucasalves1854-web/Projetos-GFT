## Sobre

Projeto desenvolvido durante a trilha **GFT - Fundamentos de Cloud com AWS** da DIO.

O laboratório demonstra a utilização do AWS CloudFormation para automatizar o provisionamento de infraestrutura através do conceito de Infrastructure as Code (IaC).
