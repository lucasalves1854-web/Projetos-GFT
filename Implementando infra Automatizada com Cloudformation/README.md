#  Implementando Infraestrutura Automatizada com AWS CloudFormation

## Descrição

Projeto desenvolvido durante o laboratório da DIO com o objetivo de compreender o funcionamento do AWS CloudFormation e do conceito de Infrastructure as Code (IaC).

---

## Recursos Criados

- Amazon S3 Bucket
- Security Group

---

## Tecnologias

- AWS CloudFormation
- YAML
- Amazon S3
- Amazon EC2
- Git
- GitHub

---


## O que aprendi

Durante este laboratório aprendi como automatizar a criação de infraestrutura utilizando templates YAML.

Com o AWS CloudFormation é possível criar, atualizar e remover recursos da AWS de maneira padronizada, reduzindo erros e aumentando a produtividade das equipes.

Também compreendi a importância da Infraestrutura como Código (IaC), permitindo que toda a configuração da infraestrutura seja versionada juntamente com o código da aplicação.
